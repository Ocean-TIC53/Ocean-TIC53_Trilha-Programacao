# Trilha de Programação — Residência TIC 53 / Ocean UnB

Este repositório reúne os materiais de planejamento e desenvolvimento dos cursos da **Trilha de Programação** do projeto **Residência em TIC 53 — Ocean/UnB**, com foco em aplicações de programação voltadas à **Saúde Digital** e na integração com outras trilhas tecnológicas do projeto.

![Diagrama da Trilha de Programação](Trilha_Docs/Diagrama%20trilha%20programacao.png)

## Cursos da trilha

| Código | Curso |
|---|---|
| **PR-01** | Lógica de Programação para Saúde com Scratch |
| **PR-02** | Aprendendo a Programar em Python para Saúde Digital |
| **PR-03** | Fundamentos de Dados para Saúde Digital com Python e Pandas |
| **PR-04** | Monitoramento de Dados de Saúde com Python |
| **PR-05** | Fundamentos de Bancos de Dados SQL para Saúde Digital |
| **PR-06** | Bancos de Dados SQL com Python para Saúde Digital |
| **PR-07** | HTML e CSS: Interfaces para Saúde Digital |
| **PR-08** | Dashboards Web com Python para Saúde Digital |
| **PR-09** | IA na Borda para Saúde Digital com Python, MicroPython e ESP32-S3 |

Os cursos são organizados como módulos curtos e práticos, com exemplos relacionados à saúde digital. A trilha também busca criar pontos de integração com áreas como **Inteligência Artificial, IoT, Backend, Frontend e Metaverso**.

## Organização do repositório

Cada diretório `PRxx_*` reúne os materiais de um curso, incluindo, conforme o estágio de desenvolvimento:

- `Plano_Curso_*.docx` — descrição geral, objetivos e ementa;
- `Plano_Aula_Detalhado_*.docx` — planejamento didático detalhado;
- `Textos_Tabela_*.txt` — textos resumidos para cadastro e divulgação;
- apresentações, links, imagens e outros materiais complementares.

A pasta [`Trilha_Docs`](Trilha_Docs/) concentra a documentação geral da trilha:

- diagrama da trilha em formatos `.drawio` e `.png`;
- proposta consolidada da Trilha de Programação;
- resumo dos cursos de Programação do catálogo Ocean.

## Objetivo

A trilha busca desenvolver competências progressivas em programação, iniciando por lógica e Python e avançando para manipulação de dados, bancos de dados, interfaces web, visualização e aplicações de IA em sistemas embarcados, sempre com abordagem prática e contextualizada.
